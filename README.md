## Run locally

Static HTML, CSS and vanilla JavaScript. No build step or third-party JavaScript runtime required.

```sh
python3 -m http.server 8080
```

Fonts are self-hosted with their SIL Open Font Licenses in `shared/fonts/licenses/`. Search, service details, session-local visit selections, copy, gallery dialogs, and mobile navigation work without a backend. Prices and hours were sourced on 21 September 2026; final details are confirmed with the business.
